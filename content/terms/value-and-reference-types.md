title: Value and reference types
topic:
  - csharp-type-fundamentals
---

The two categories every C# type falls into: a value-type variable holds the instance itself, a
reference-type variable holds a reference to one elsewhere. That single distinction drives copy
semantics, default equality, where an allocation happens, and the boxing that bridges the two.
