topic:
  - data-structures-and-algorithms

A collection that maps keys to values by hashing the key to a bucket, trading memory for
lookup speed — the amortised O(1) lookup that makes it the default answer whenever a question
turns on [[big-o-notation|how fast a lookup grows]].
